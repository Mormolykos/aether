# Embodied prototype\n\nThis branch explores whether Aether's validated physical-state pipeline can provide a deterministic boundary underneath a learned robot language policy.\n\nIt is deliberately small. It does **not** turn Aether into a robot controller.\n\n## Boundary\n\n    natural-language command\n            |\n            v\n    learned grounding / VLA\n            |\n            | GroundedCommand { original utterance, language, confidence, typed Goal }\n            v\n    deterministic decision gate <----- WorldState <----- tracking / fusion <----- sensors\n            |\n            | ActionIntent\n            v\n    planner / safety controller / robot-specific actuator stack\n\nThe learned component may interpret language. It is not allowed to hide which target or high-level action it selected. The original utterance and typed goal remain available for evaluation.\n\nThe deterministic gate refuses missing or ambiguous target identities, stale evidence, low-confidence grounding, low-confidence tracked entities, non-finite physical state, and invalid stand-off distances.\n\nThe output is a high-level ActionIntent, never a wheel speed, servo position or joint torque.\n\n## Why this connects to language-transfer research\n\nA policy can appear to obey a Greek command while relying on partial lexical cues. This boundary makes that failure directly testable. A benchmark can hold the scene fixed and change exactly one semantic slot: object/person identity, destination, spatial relation, negation or stop condition, while separately varying paraphrase, morphology and word order.\n\nThe evaluator can compare the original Greek utterance, the grounded typed Goal, the resolved physical track, the admitted/rejected ActionIntent, and the eventual motion outcome. That separates language understanding, persistent tracking and physical execution instead of collapsing all three into one success rate.\n\n## Relationship to existing Aether\n\nExisting Aether remains the aircraft/telemetry demonstrator and keeps its current safety claims. The new embodied module is an experimental interface layer.\n\nExisting core: observation -> persistent track -> deterministic decision\n\nEmbodied extension: command -> grounded goal -> world state -> admitted high-level action\n\nNo direct LLM/VLA-to-motor path is introduced.\n\n## Next experiments\n\n1. Add deterministic replay with moving people and obstacles.\n2. Add an adapter from tracked sensor state into WorldState.\n3. Construct Greek/English minimal-pair commands with wrong-target and wrong-destination nulls.\n4. Measure goal-grounding accuracy separately from trajectory success.\n5. Only after the interface is stable, add simulator/ROS2 adapters.\n\nThis branch is civilian and safety-oriented: navigation, following, inspection, collision avoidance and human-robot interaction. It contains no targeting, engagement, weapon or fire-control functionality.\n
